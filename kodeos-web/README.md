# KodeOS Web Simulator (experimental)
This branch contains a GitHub Actions build pipeline for the **original** KodeOS GUI simulator.
The workflow clones the official KodeOS and kode-sdk sources and compiles using Emscripten.
No precompiled or tested browser build is included. Check Actions for compiler diagnostics.
The branch is isolated from the main project. The sources are GPL-3.0-or-later.
